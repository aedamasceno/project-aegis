# Security and responsible use

Project AEGIS is in planning and has not been security-audited or approved for operational use.

- **Do not upload real case files, criminal justice information, personal data, credentials, or confidential agency policies** to this public repository or its issues.
- Use synthetic or expressly authorized data for development and public demonstrations.
- Do not rely on AI output for probable cause, arrests, detention, identification, use of force, or any other legal or operational determination.
- Verify every output, source citation, and jurisdiction-specific reference independently.
- Treat generated narratives as unverified drafts until reviewed by an authorized person.
- Deployments handling sensitive records will require agency authorization, security review, applicable CJIS/security requirements, access control, retention policies, audit logs, and incident response procedures.

Please do not post exploitable vulnerability details publicly. For now, open a GitHub issue requesting a private reporting channel **without including vulnerability details**.
