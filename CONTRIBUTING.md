# Contributing to Project AEGIS

Thank you for your interest. The project is in its planning stage.

Useful early contributions include design reviews, threat-model suggestions, accessible UI ideas, repeatable evaluation methods, and documentation improvements.

Please open an issue describing the proposed change before investing in major work. Avoid submitting personal information, agency secrets, operational case details, or non-redistributable documents.

Contributions should preserve human decision-making and traceability, avoid unsupported legal claims, and use synthetic test data unless explicitly authorized. Code submissions should include tests and clear setup instructions when applicable.
